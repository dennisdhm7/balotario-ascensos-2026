# Balotario de Ascensos CGBVP 2026

Aplicación web de práctica y simulacros basada en el PDF de 200 preguntas aportado por el usuario.

## Publicación

Subir `index.html`, `style.css`, `app.js` y `questions.json` a la raíz de la rama `main`. Después, en Settings → Pages, seleccionar Deploy from a branch → main → /(root) y guardar.

La clave de respuestas procede del balotario proporcionado y no ha sido verificada independientemente. El progreso se guarda en el navegador del estudiante.
